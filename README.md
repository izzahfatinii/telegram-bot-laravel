# Telegram Grammar & Word Meaning Bot

Backend for a Telegram bot that uses **Gemini 2.0 Flash** to check sentence grammar and provide word meanings.

## Tech Stack

- Laravel 9
- PHP
- Gemini 2.0 Flash API
- Telegram Bot API

## Note

This project was created last year using Laravel 9 and Gemini 2.0 Flash via API key. The Gemini API integration may require updates to work with the latest API version.
