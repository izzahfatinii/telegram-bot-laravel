# Telegram Grammar & Word Meaning Bot

Backend for a Telegram bot that uses **Gemini 2.0 Flash** to check sentence grammar and provide word meanings.

## Tech Stack

- Laravel 9
- PHP
- Gemini 2.0 Flash API
- Telegram Bot API

## Note

This project was created using Laravel 9 and integrated with **Gemini 2.0 Flash** via API key. The Gemini API integration was implemented at the time of development and may require updates to be compatible with the latest Gemini and available models.
